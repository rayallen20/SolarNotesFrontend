## 1. 源 → 组件:两套结构(`render.js`)

> 本节是**源**结构,类名沿用源的 camelCase(`articleBody` / `articleActive` / `articleInactive` / `bottomButton` / `createdAt` / `articleContent` / `leftTrapezoid` / `hasMask`);迁到 Vue 后这些多词类名一律改 **kebab**(`article-body` / `article-active` / …,见 §0 结构图与 §3 代码)。
>
> 此外,下方两个标题括号里的相位值 `renderNonleaf`/`renderLeaf` 同样是**源** `render.js` 的 `state.phase` 裸串(源里是小写 `l` 的 `nonleaf`);迁到 Vue 收敛为枚举 `RenderPhase.nonLeaf`/`RenderPhase.leaf`(定义见 doc2《目录树》§2.1),§3 起一律用枚举、不再写裸串。

源右侧用「固定骨架 + 切换内容」。两态结构:

**非激活(renderNonleaf,初始态:展示节点简介)**
```html
<div class="article articleInactive">
  <div class="articleBody" data-simplebar>
    <h2 class="title">节点名</h2>
    <div class="articleContent content">简介 intro</div>
    <span class="createdAt">2026-01-22</span>
  </div>
  <button class="bottomButton">开启文章</button>
</div>
```

**激活(renderLeaf,打开文件:展示 Markdown)**
```html
<div class="article articleActive">         <!-- 专注目录时加 .hasMask -->
  <div class="articleBody" data-simplebar>
    <h2 class="title">
      <div class="leftTrapezoid"></div>
      <div class="literal">文件名</div>
    </h2>
    <div class="articleContent markdown-body"><!-- v-html 渲染后的 HTML --></div>
    <span class="createdAt">2026-01-22</span>
  </div>
  <button class="bottomButton">
    <i class="iconfont icon-icon_mulu"></i>   <!-- ← 源 icon-mulu -->
    <span class="literal">专注目录</span>
  </button>
</div>
```

要点:
- `.createdAt` 在 `.articleBody` **内部**(正文之后);`.bottomButton` 是 `.articleBody` 的**兄弟**(绝对定位贴底)。
- 非激活正文 = `.articleContent.content`(纯文本简介);激活正文 = `.articleContent.markdown-body`(`v-html`)。
- 蒙版:`.article` 加 `.hasMask` → `.articleActive.hasMask .articleBody::after` 显示(专注目录态)。
