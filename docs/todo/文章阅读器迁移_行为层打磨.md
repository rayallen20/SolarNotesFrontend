## 1 + 2. `useCollapseTransition` 最终版(reduced-motion + 打断 + 强展开跳过)

这版**取代** 2b 的同名文件。三处增强:① `prefers-reduced-motion` 或强展开 → 瞬时落位不动画;② 代际令牌打断旧动画(快速连点不打架);③ 多收一个 `nodeId` 入参。

> **先抽公共 lib**:`prefersReducedMotion` 原在本文件内定义,但 `ensureNodeVisible`(2c §3)也要做同一判断。它只读全局 `window`、零闭包依赖,按「函数住在其全部依赖仍可见的最外层」可上提到 `src/lib/` 共享——两处 import 同一份,既消重复,也避免那条 media 查询串在两处被改歪后**静默分叉**。注意只抽这个谓词本身:behavior 的解析(`? 'auto' : behavior` / 强展开瞬时落位)两处用法不同,不并入 lib。

**新建 `src/lib/prefersReducedMotion.js`**:

```js
/**
 * 本函数用于读取系统级「减少动态效果」偏好
 * @return {Boolean} true: 用户偏好减少动画 / false: 无此偏好
 * */
export function prefersReducedMotion() {
    if (window.matchMedia) {
        return window.matchMedia('(prefers-reduced-motion: reduce)').matches
    } else {
        return false
    }
}
```

**`ensureNodeVisible`(2c §3,已落地)同步 retrofit**:删掉内联的 `let prefersReducedMotion = false; if (window.matchMedia) {...}`,改成 import + 在 scrollTo 处内联调用(顺带消掉那个局部变量):

```js
import { prefersReducedMotion } from '@/lib/prefersReducedMotion.js'

// ……scrollTo 处:
scrollElement.scrollTo({
    top: Math.max(0, targetTop),
    behavior: prefersReducedMotion() ? 'auto' : behavior,
})
```

**`stores/article.js` 增量**(强展开标记;非响应式,仅作一次性跳过动画的旁路):
```js
// 在 setup 内、actions 上方:
const forceExpandedIds = new Set() // 本次"强展开"待跳过动画的文件夹 id(一次性)

function expandFolders(ids) {
    ids.forEach(id => {
        // 只标记真正「折叠→展开」的:已展开的 id 不触发动画,留标记反而会吞掉它下次手动切换的动画
        if (collapsedIdSet.value.has(id)) {
            collapsedIdSet.value.delete(id)
            forceExpandedIds.add(id)
        }
    })
}

/**
 * 本函数用于消费"强展开跳过动画"标记(composable 在 watch 中调一次)
 * @param {Number} id 文件夹 id
 * @return {Boolean} 命中则 true 并清除标记
 * */
function consumeForceExpanded(id) {
    if (forceExpandedIds.has(id)) {
        forceExpandedIds.delete(id)
        return true
    }
    return false
}

// return 里补:expandFolders(覆盖 2a 版)、consumeForceExpanded
```

下面 `useCollapseTransition` 最终版同时用到上面两者(import `prefersReducedMotion` lib、调 store 的 `consumeForceExpanded`),本地不再定义 `prefersReducedMotion`:

```js
import { nextTick, ref, watch } from 'vue'
import { useArticleStore } from '@/stores/article.js'
import { prefersReducedMotion } from '@/lib/prefersReducedMotion.js'

/**
 * 本 composable 用于文件夹展开 / 折叠的高度过渡(命令式 DOM 副作用)
 * @param {import('vue').Ref<HTMLElement|null>} elementRef 被动画的 <ul> 元素 ref
 * @param {() => Boolean} isCollapsed 读取当前折叠态的 getter
 * @param {Number} nodeId 本节点 id(用于消费"强展开跳过动画"标记)
 * @return {{ isAnimating: import('vue').Ref<Boolean> }}
 * */
export function useCollapseTransition(elementRef, isCollapsed, nodeId) {
    const isAnimating = ref(false)
    const articleStore = useArticleStore()
    let token = 0 // 代际令牌:每次切换 +1,旧回调据此自我作废

    /**
     * 本函数用于播放一次折叠 / 展开的高度过渡
     * @param {Boolean} collapsed 本次切换的目标态:true 折叠 / false 展开
     * */
    async function playTransition(collapsed) {
        const element = elementRef.value
        if (element === null) {
            return
        }

        // 强展开(openArticle 沿途)或 reduced-motion:瞬时落位,不动画
        if (articleStore.consumeForceExpanded(nodeId) || prefersReducedMotion()) {
            element.style.height = collapsed ? '' : 'auto'
            isAnimating.value = false
            return
        }

        const current = ++token
        const startHeight = collapsed ? element.scrollHeight : 0
        const endHeight = collapsed ? 0 : element.scrollHeight

        element.style.height = startHeight + 'px'
        isAnimating.value = true

        await nextTick()
        if (current !== token) {
            return // 已被新一次切换接管,放弃本次
        }
        element.offsetHeight
        element.style.height = endHeight + 'px'

        function onTransitionEnd(event) {
            if (event.propertyName !== 'height') {
                return
            }
            if (current === token) {
                element.style.height = collapsed ? '' : 'auto'
                isAnimating.value = false
            }
            element.removeEventListener('transitionend', onTransitionEnd)
        }
        element.addEventListener('transitionend', onTransitionEnd)
    }

    watch(isCollapsed, playTransition)

    return { isAnimating }
}
```

**`TreeNode` 改一行**(多传 `nodeId`):
```js
const {isAnimating} = useCollapseTransition(childrenRef, () => isCollapsed.value, props.node.id)
```

> 这样 `openArticle` 沿途展开**瞬时完成**,2c §4 的"滚动撞上动画"问题随之消失:`ensureNodeVisible` 在 `nextTick` 时路径已展平,目标位置稳定。

## 3. 根行免折叠(取舍)

2b 里点根行(depth 0,是 folder)会 `toggleCollapsed(根)` → 整棵树折叠。源行为如此,但通常非预期(根一折叠目录全空)。**推荐**给 `onRowClick` 加根守卫:

```js
function onRowClick() {
    // 根(depth 0)不参与折叠:折叠根会隐藏整棵树
    if (props.node.type === CatalogueNodeType.folder && props.depth !== 0) {
        articleStore.toggleCollapsed(props.node.id)
    }
    articleStore.selectNode(props.node.id)
}
```

点根仍会 `selectNode(根)`(渲染根简介),只是不再折叠。若你确实想保留源的"点根折叠全部",跳过本条即可。

## 4. 折叠 / 展开后 SimpleBar 重算(按需)

目录内容高度随折叠 / 展开变化,SimpleBar 滑块可能需重算。SimpleBar v6 内置 ResizeObserver/MutationObserver,**多数情况自动重算**——先按 2b/2c **不加**手动重算实测:滚动条尺寸 / 可拖动性正常就到此为止。若发现折叠后滑块不更新,再在 `CatalogueTree` 补:

```js
// onMounted 里保留实例:const scrollbar = new SimpleBar(rootRef.value)
watch(() => articleStore.collapsedIdSet.size, async () => {
    await nextTick()
    scrollbar?.recalculate()
})
```

> 同理核对 2c 文章区:`watch(activeNode)` 的重算是否必要(SimpleBar 自动则可删)。**能不手动就不手动**,避免与内置 observer 重复。
