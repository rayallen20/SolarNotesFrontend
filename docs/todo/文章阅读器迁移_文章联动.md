## 1. ⚠ 先厘清:专注态文章列**仍是 `.article-active`**(细化《总览》§4)

布局三态(`renderPhase` × `focusedPane`):

| 态 | 目录列 class | 文章列 class | 文章宽 | 按钮 |
|---|---|---|---|---|
| 浏览 `nonLeaf` | `catalogue-active` | `article-inactive` | 窄 | `.bottom-button` 整条「开启文章」→ `openArticle` |
| 阅读 `leaf,article` | `catalogue-inactive` | `article-active` | 70% | `.bottom-button` 胶囊「专注目录」→ `focusCatalogue` |
| 专注 `leaf,catalogue` | `catalogue-active` | **`article-active` + `.has-mask`** | 窄 | `.has-mask-button` 整条「开启文章」→ `focusArticle` |

关键:专注态文章列**不切到 `.article-inactive`**——它要保留 `.article-active` 的梯形标题 flex + markdown 布局,而且现有蒙版 CSS 就是 `.article-active.has-mask .article-body::after`(doc《文章区》§3 已有)。专注只做三件事:**`.has-mask` 收窄宽度 + 显蒙版 + 按钮换 `.has-mask-button`**。所以:

- 文章列 `stateClass` 由 `renderPhase` 决定(`leaf`→active),**与你现在的 ArticlePane 一致**,只是相位改读 store 的 `renderPhase`;
- 收窄 = 新增一条 `.article-active.has-mask { width: 窄 }`;
- 蒙版 = `articleStore.hasMask` 绑 `.has-mask`(蒙版 `::after` 已就绪);
- 按钮三态见 §2。

## 3. 新建 `src/lib/ensureNodeVisible.js`

搬源 `interaction/toggleFolder.js` 的 `ensureNodeVisible`,选择器按本项目改 `.tree-node[data-id]`(doc《目录树》§8:认 `data-id` 最稳)。

```js
/**
 * 本函数用于在 SimpleBar 目录容器内把指定节点滚进视口
 * @param {HTMLElement|null} catalogueElement 目录根元素(.catalogue-tree)
 * @param {Number|null} targetNodeId 目标节点 id
 * @param {{behavior: ScrollBehavior, block: 'center'|'nearest'}} options 滚动选项
 * */
export function ensureNodeVisible(catalogueElement, targetNodeId, options) {
    if (catalogueElement === null || targetNodeId === null) {
        return
    }

    const {behavior, block} = options
    // block 取值域钉死 center|nearest,下面据此用两个并排 if 分派(而非 else if)
    if (block !== 'center' && block !== 'nearest') {
        return
    }

    const targetLiElement = catalogueElement.querySelector(`.tree-node[data-id="${targetNodeId}"]`)
    if (targetLiElement === null) {
        return
    }

    // SimpleBar 的真实滚动容器
    const scrollElement = catalogueElement.querySelector('.simplebar-content-wrapper')
    if (scrollElement === null) {
        targetLiElement.scrollIntoView({behavior, block, inline: 'nearest'})
        return
    }

    // 已在视口内则不处理
    const targetRect = targetLiElement.getBoundingClientRect()
    const wrapRect = scrollElement.getBoundingClientRect()
    if (targetRect.top >= wrapRect.top && targetRect.bottom <= wrapRect.bottom) {
        return
    }

    const currentTop = scrollElement.scrollTop
    let targetTop = currentTop + (targetRect.top - wrapRect.top)

    if (block === 'center') {
        targetTop = targetTop - (wrapRect.height / 2) + (targetRect.height / 2)
    }

    if (block === 'nearest') {
        // 顶 / 底可能同真(目标比视口高),内层必须 else if:优先顶部对齐
        if (targetRect.top < wrapRect.top) {
            targetTop = currentTop + (targetRect.top - wrapRect.top)
        } else if (targetRect.bottom > wrapRect.bottom) {
            targetTop = currentTop + (targetRect.bottom - wrapRect.bottom)
        }
    }

    let prefersReducedMotion = false
    if (window.matchMedia) {
        prefersReducedMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches
    }

    scrollElement.scrollTo({
        top: Math.max(0, targetTop),
        behavior: prefersReducedMotion ? 'auto' : behavior,
    })
}
```

## 4. 改 `src/components/article/CatalogueTree.vue`:接滚动

在 2b 的脚本上补 `pendingRevealId` 的 watch:

```vue
<script setup>
import {computed, onMounted, useTemplateRef, watch, nextTick} from "vue";
import SimpleBar from "simplebar";
import TreeNode from "@/components/article/TreeNode.vue";
import {treeData} from "@/data/treeData.js";
import {useArticleStore} from "@/stores/article.js";
import {ensureNodeVisible} from "@/lib/ensureNodeVisible.js";

defineOptions({
    name: 'CatalogueTree',
})

/**
 * @type {import('@/stores/article.js').ArticleStore} 文章阅读器状态机的引用
 * */
const articleStore = useArticleStore()

/**
 * @type {import('vue').ComputedRef<String>} 目录区当前状态对应的CSS类名
 * */
const stateClass = computed(() => {
    return articleStore.isCatalogueActive ? 'catalogue-active' : 'catalogue-inactive'
})

const rootRef = useTemplateRef('root')

onMounted(() => {
    new SimpleBar(rootRef.value)
})

// openArticle 后:把目标文件夹滚进目录视口
watch(() => articleStore.pendingRevealId, async (revealId) => {
    if (revealId === null) {
        return
    }
    await nextTick()
    ensureNodeVisible(rootRef.value, revealId, {behavior: 'smooth', block: 'center'})
    articleStore.clearPendingReveal()
})
</script>
```

> ⚠ **已知时序问题(留 2d)**:`openArticle` 里 `expandFolders` 删 `collapsedIdSet` 会触发路径上文件夹的**展开动画**(2b 的 `useCollapseTransition`);此处 `nextTick` 后滚动可能在动画**未结束**时执行,目标位置还在变。源用「无动画强展开」规避。2d 收口(给 `expandFolders` 一个跳过动画的通道,或等动画结束再滚)。
