# 收尾 · 梯形组件收敛(Trapezoid 参数化)

> **目标**:把全项目「右边对称掐角的竖直梯形」母题收敛到一个参数化的 `Trapezoid.vue`。该母题共 **4 处**:`Trapezoid.vue`(被 `PanelList`、`InnerDecorLayer` 使用)+ `ArticlePane` 标题裸 div + `CatalogueTree` 根行裸 div(实际 div 在 `TreeNode.vue`)。
>
> **已确认决策**:
> - **组件只管纯色,单一职责**:`color` 收纯色,`width`/`height`/`inset` 决定形状,`clip-path` 内部按三数推导(换尺寸不变形,根治旧「写死多边形」的坑)。
> - **clip-path 内部推导**:四处拓扑一致 `polygon(0 0, W I, W H−I, 0 H)`,只 W/H/掐角 I 不同。
> - **label 渐变保留、但下放到 InnerDecorLayer 本地**:渐变是 label 语境的特殊需求、仅此一处用,co-locate 在 `InnerDecorLayer` 自己的 scoped CSS(组件不背负渐变对齐机械)。
> - **配色分配**:组件默认 `#20C6D8`;PanelList / ArticlePane / CatalogueTree 用默认青;InnerDecorLayer 传 `transparent` 当底、再用 `background-image` 叠自己的 `#51BCFF` 竖直渐变。
>
> **不在范围内(别动)**:`LuminousAction`(六边形按钮)、`Shape`(标签外框含凹口)、`OuterDecorLayer`(边框 / 平行四边形传送带)、`CutOffLine`(3px 切割线)是不同母题的 clip-path,与本母题无关。
>
> **触及**:`common/Trapezoid.vue`(重写)、`label/shape/InnerDecorLayer.vue`、`article/ArticlePane.vue`、`article/TreeNode.vue`、`article/CatalogueTree.vue`。**PanelList 无需改动**。

## 0. 四处实例对照(收敛依据)

| 实例 | W×H | inset I | 旧 clip-path | 旧填充 | 收敛后 |
|---|---|---|---|---|---|
| Trapezoid.vue / PanelList | 8×33 | 5 | `0 0, 8 5, 8 28, 0 33` | 蓝渐变 | `<Trapezoid/>`(默认青纯色) |
| InnerDecorLayer | 8×33 | 5 | 同上 | 蓝渐变(对齐全高) | `<Trapezoid :color="'transparent'"/>` + 本地渐变 |
| ArticlePane 标题 | 8×40 | 7 | `0 0, 8 7, 8 33, 0 40` | 实色 `#20C6D8` | `<Trapezoid :height="40" :inset="7"/>` |
| CatalogueTree 根行 | 6×24 | 5 | `0 0, 6 5, 6 19, 0 24` | 实色 `#20C6D8` | `<Trapezoid :width="6" :height="24"/>` |

> 校验:`H−I` 各为 28 / 28 / 33 / 19,与旧 clip-path 第三点 y 值一一对上。

## 1. 重写 `src/components/common/Trapezoid.vue`

整文件替换为(只管纯色;`background-color` 用**长名**,以便 InnerDecorLayer 能用 `background-image` 在其上叠渐变):

```vue
<template>
    <div class="trapezoid" :style="trapezoidStyle"></div>
</template>

<script setup>
import {computed} from "vue";

defineOptions({
    name: 'Trapezoid',
})

const props = defineProps({
    width: {
        type: Number,
        default: 8,
    },
    height: {
        type: Number,
        default: 33,
    },
    inset: {
        type: Number,
        default: 5,
    },
    color: {
        type: String,
        default: '#20C6D8',
    },
})

/**
 * @type {import('vue').ComputedRef<Object>} 梯形的尺寸 / 形状 / 纯色填充内联样式
 * clip-path 由宽高与掐角推导,右边上下各掐 inset,换尺寸不变形
 * */
const trapezoidStyle = computed(() => ({
    width: `${props.width}px`,
    height: `${props.height}px`,
    backgroundColor: props.color,
    clipPath: `polygon(0 0, ${props.width}px ${props.inset}px, ${props.width}px ${props.height - props.inset}px, 0 ${props.height}px)`,
}))
</script>
```

- 尺寸 / 形状 / 纯色填充全部由 `:style` 内联给出,组件自身**不再需要 `<style>` 块**(整段删掉)。
- 旧的 `--vertical-grad` / `--gradient-height` / `--gradient-offset` / `background-size` / `background-position` 全部从组件移除——渐变改由 InnerDecorLayer 本地承担(见 2.2)。

## 2. 调用点

### 2.1 `PanelList.vue` —— 无需改动

现有 `<Trapezoid></Trapezoid>` 原样保留:默认即 8×33、掐 5、纯色 `#20C6D8`。此处旧的蓝渐变本是「自包含默认渐变」,改纯色后只是从蓝渐变变青纯色,模板与样式都不动。

### 2.2 `InnerDecorLayer.vue` —— 渐变下放到本地

**模板**:传透明底(不要纯色填充,渐变自己叠):

```html
<!-- 左侧竖梯形开始 -->
<Trapezoid :color="'transparent'" class="left"></Trapezoid>
<!-- 左侧竖梯形结束 -->
```

**样式**:`.inner-decor-layer .left` 保留定位,**把渐变直接写在这里**(等价于旧组件的 `--vertical-grad` + `--gradient-height/offset`,只是直写、去掉中转变量):

```css
.inner-decor-layer .left {
    position: absolute;
    top: 26px;
    left: 3px;
    /* label 的竖直渐变(亮→暗→亮),由组件的 background-color:transparent 透出 */
    background-image: linear-gradient(
        180deg,
        rgba(81, 188, 255, 1) 0%,
        rgba(81, 188, 255, 0.1) 50%,
        rgba(81, 188, 255, 1) 100%
    );
    /* 渐变铺满标签全高、再上移 26px 抵消 top,使其对齐标签坐标系(像旧那样从全高渐变上抠一段) */
    background-size: 100% var(--height);
    background-position: 0 -26px;
    background-repeat: no-repeat;
}
```

> 三点对应旧实现:`background-image` = 旧 `--vertical-grad` 默认值;`background-size: 100% var(--height)` = 旧 `background-size: 100% var(--gradient-height)`(`--gradient-height` 旧即 `var(--height)`);`background-position: 0 -26px` = 旧 `0 calc(-1 * var(--gradient-offset))`(`--gradient-offset` 旧即 `26px`)。像素一致。
>
> 关键:组件内联的是 `background-color`(长名),这里叠的是 `background-image`(另一条长名),两者并存不互斥;`background-size/position` 组件没设、由此处独占。

### 2.3 `ArticlePane.vue`

**① import**:script 顶部 import 区加一行

```js
import Trapezoid from "@/components/common/Trapezoid.vue";
```

**② 模板**:标题里的裸 div 换成组件

```html
<h2 class="title">
    <Trapezoid :height="40" :inset="7"></Trapezoid>
    <div class="literal">{{articleStore.activeNode.name}}</div>
</h2>
```

> `width` 用默认 8,故只传 `height`/`inset`;`.title` 仍是 `display:flex; column-gap:20px`,梯形作为首个 flex 子项,尺寸由 prop 给出。

**③ 样式**:删掉整段 `.left-trapezoid` 规则

```css
/* 删掉这一整块 */
.article-active .title .left-trapezoid {
    width: 8px;
    height: 40px;
    background: #20C6D8;
    clip-path: polygon(0px 0px, 8px 7px, 8px 33px, 0px 40px);
}
```

### 2.4 `TreeNode.vue` + `CatalogueTree.vue`

目录树根行的梯形:**div 在 `TreeNode.vue`,样式在 `CatalogueTree.vue`**,两边各改一处。

**① `TreeNode.vue` import**:

> `inset` 用默认 5(6×24×5 与旧 `polygon(0 0,6 5,6 19,0 24)` 等价);`.primary-row` 仍是 `display:flex; column-gap:10px`。

**③ `CatalogueTree.vue` 样式**:删掉整段 `.primary-row .left-trapezoid` 规则

```css
/* 删掉这一整块 */
.primary-row .left-trapezoid {
    width: 6px;
    height: 24px;
    background: #20C6D8;

```

## 4. 备注

- 收敛后该母题单一真相源 = `Trapezoid.vue`(纯色 + 形状),尺寸 / 掐角 / 颜色走 props、clip-path 由三数推导;后续新增同款纯色梯形直接 `<Trapezoid :width :height :inset :color>`。
