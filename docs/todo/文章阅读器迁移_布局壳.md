## 2. 新建 `src/components/article/ReaderBody.vue`

```vue
<template>
    <div class="reader-body">
        <CatalogueTree class="pane" />
        <ArticlePane class="pane" />
    </div>
</template>

<script setup>
import CatalogueTree from "@/components/article/CatalogueTree.vue";
import ArticlePane from "@/components/article/ArticlePane.vue";

defineOptions({
    name: 'ReaderBody',
})
</script>

<style scoped>
/* 源 articleWrap.css 的 .articleWrap:header 之下吃满剩余高度的左右两栏容器 */
.reader-body {
    flex: 1 1 auto;
    /* 防止内部把滚动传给页面 */
    overflow: hidden;
    display: flex;
    justify-content: space-between;
    column-gap: 31px;
    padding: 29px 100px 49px;
}

/* 源 articleWrap.css 的 `.articleWrap .catalogue, .articleWrap .article`:
   两个面板共用的「有界高度 + 可滚动 + 描边卡片」。
   class="pane" 加在子组件标签上 → 合并到子组件根元素;该根元素同时带 ReaderBody 的 scope 属性,
   故 .pane(scoped 编译成 .pane[data-v-xxx])能命中两个子根,无需 :deep()。 */
.pane {
    height: 100%;
    min-height: 0;
    overflow: auto;
    border-radius: 20px;
    border: 1px solid #21AAFF;
    background: linear-gradient(90deg, rgba(0, 0, 0, 0.30) 0.23%, rgba(0, 0, 0, 0.30) 99.78%);
}

/* ⚠ 临时宽度:仅为布局壳阶段让两栏可见。
   第 2/3 份接行为时,宽度+过渡改由 catalogue.css/article.css 的 active/inactive 状态类驱动,这两条删掉。 */
.pane:first-child { width: 70%; }                     /* 目录区(落地初始态占大头) */
.pane:last-child  { width: calc(100% - 70% - 31px); } /* 文章区 */
</style>
```

**`class="pane"` 为什么能命中子组件根**:把 class 写在子组件标签上,Vue 会把它合并到子组件的**单一根元素**上;而 Vue 又总会给子组件根元素补上**父组件的 scope 属性**——所以子根同时有 `pane` 类和 `data-v-readerbody`,父级 scoped 规则 `.pane[data-v-readerbody]` 正好命中。两个占位组件都是单根(§3),满足条件。

## 5. 为什么这条高度链能滚(布局壳的核心)

```
.article-reader  height:100vh; display:flex; flex-direction:column   ← 视口定高
├── HeaderBar    flex:0 0 100px                                       ← 固定 100px
└── .reader-body flex:1 1 auto; overflow:hidden                       ← 吃满剩余高度(得到确定高度)
    └── .pane    height:100%; min-height:0; overflow:auto             ← 在确定高度内滚动
```

- `.article-reader` 用 `100vh` 拿到确定高度(上一份 header 已把 `100%` 修成 `100vh`);列方向 flex。
- `HeaderBar` 固定 100px,`ReaderBody` `flex:1 1 auto` 吃掉剩余 → ReaderBody 得到**确定高度**。
- `ReaderBody` `overflow:hidden` 把溢出关在自己内部(源注释:防止把滚动传给 `body`)。
- 面板 `height:100%` 贴合 ReaderBody 内容高;**`min-height:0` 是关键**——flex 子项默认 `min-height:auto` 会被内容撑高、顶破容器;置 `0` 才允许它收缩进容器高度内,`overflow:auto` 才真正滚动。

## 6. 留松 / 接缝(实现第 2/3 份前回看)

- **⚠ 宽度**:`.pane:first-child/last-child` 的 `70%` / `calc` 是**临时**。第 2/3 份接 `catalogue.css`(`.catalogueActive/Inactive`)、`article.css`(`.articleActive/Inactive`)状态类时,宽度+过渡由状态驱动 → **删掉这两条临时规则**。
- **⚠ SimpleBar**:本份两栏用**原生 `overflow:auto`**。第 2 份给目录、第 3 份给文章内层 `.article-body` 各自 `new SimpleBar(el)`(`onMounted`)并用 `:deep(.simplebar-*)` 调样式;届时 `.pane` 的 `overflow` 可能要让位(SimpleBar 自管滚动)。
- **⚠ 文章区外层 overflow**:源 `article.css` 把 `.article` 设 `overflow:hidden`、改用内层 `.article-body` 滚动。第 3 份会把文章面板的 `.pane { overflow:auto }` 覆盖成 `hidden`。布局壳阶段先让两栏都原生滚,便于肉眼验证。
- **子组件根类名无需提前定死**:ReaderBody 给子标签加 `class="pane"`,**不依赖**子组件自己的根类名(`.catalogue-tree`/`.article-pane`);第 2/3 份即便改子根类名,卡片几何照样命中。
- **`--tree-*` 变量 / `button` 重置**:本份**不加**(分别留第 2 / 第 3 份,见设计文档 §8 表)。
