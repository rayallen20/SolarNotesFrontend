# 架构总纲

> 这份文档是整个 3D 太阳系子系统的入口。新读者按下面顺序读 → 心智模型 → 跳到对应专题深入。

## 1. 项目定位

基于 **Three.js + Vue 3 + Vite** 的 3D 太阳系可视化工程,从原 Webpack 工程([universeBlog](https://github.com/rayallen20/universeBlog/tree/onlyWebpack))迁移而来。当前主要由 `src/three/` 目录承载,`Vue` 组件层负责挂载与生命周期,3D 逻辑全部封装在 `src/three/` 内,**与 Vue 解耦**。

入口函数:`src/three/engine.js` 的 `initEngine(container)`,返回 `dispose` 函数。

## 2. 系统骨架(顶层 scene graph)

```
scene
├── skySphere                          天空球(背景球,自转)
├── sunAxis                            太阳自转轴组(倾角层 + 拾取锚点)
│   └── sunRoot                         (实际承载自转的层)
│       ├── sunModel                    太阳 GLTF 模型
│       └── lightGroup                  光源组(4 盏)
│           ├── principalLight          主光源 (PointLight, castShadow)
│           ├── fillLight               远距离补光 (PointLight, layer: outerPlanets)
│           ├── shadowToneLight         阴影色调光 (HemisphereLight, layer: outerPlanets)
│           └── blackLiftLight          黑位提升光 (AmbientLight, layer: outerPlanets)
├── planet[0..7].axis                   8 颗行星的轨道倾角层
│   ├── planet[i].root                   公转层(在轨道上的位置)
│   │   └── planet[i].spin                自转层
│   │       └── planet[i].model            行星 GLTF 模型
│   └── planet[i].orbitPath              轨道线 LineLoop
└── axesHelper                          坐标轴辅助线(仅 DEV)
```

每个子系统的"对外接口"(脚本里 export 的内容):

|            模块             |               入口               |                                主要导出                                |
|:---------------------------:|:--------------------------------:|:----------------------------------------------------------------------:|
|    `src/three/engine.js`    |     `initEngine(container)`      |                               `dispose`                                |
|  `src/three/skySphere.js`   |     `initSkySphereTexture()`     |                     `skySphere`、`setAutoRotation`                     |
|     `src/three/sun.js`      |           `initSun()`            |             `sunAxis`、`setAutoRotation`、`pickableMeshes`             |
| `src/three/planet/index.js` |         `initPlanets()`          |           `planets`、`updatePlanets`、`getAllPickableMeshes`           |
| `src/three/postProcess.js`  |        `initComposers()`         | `markAsBloomObject`、`renderBloomFrame`、`resizeBloom`、`disposeBloom` |
|  `src/three/base/scene.js`  | `initSceneEnvironment(renderer)` |                                `scene`                                 |

## 3. 核心约定

### 3.1 坐标系(Three.js 默认)

- **Y 轴朝上**,**XZ 平面是水平面**
- 太阳系轨道平面 ≈ XZ 平面(轨道倾角通过 `axis.rotation.x = degToRad(dipAngle)` 实现微小翘起)
- 太阳位于场景原点 (0, 0, 0)

### 3.2 角度 vs 弧度

- **配置文件**(给人看)用**角度**,字段名带 `Angle`(例:`dipAngle: 7.0` —— 水星轨道倾角 7°)
- **运行时**(代码内部累积/传给数学函数)用**弧度**,字段名带 `Rad`(例:`orbitRad`)
- 边界处用 `THREE.MathUtils.degToRad()` 转一次,中间不来回转
- 详见 [角度与弧度.md](../explain/角度与弧度.md)

### 3.3 命名约定

|           内容           |                                           命名                                            |
|:------------------------:|:-----------------------------------------------------------------------------------------:|
| 每颗天体的 3 个 Group 名 |              camelCase + 后缀:`mercuryAxis` / `mercuryRoot` / `mercurySpin`               |
|  拾取所需 userData 字段  | `bodyType` / `label` / `intro`(挂在 `axis` 或 `root` 上)+ `anchorPointName`(挂在 Mesh 上) |
|        弧度类字段        |                                         `xxxRad`                                          |
|        角度类字段        |                                        `xxxAngle`                                         |

### 3.4 图层(Three.js Layers)系统

`src/three/base/layers.js` 集中定义了几个图层枚举,目前用到:

|         图层          |                            用途                             |
|:---------------------:|:-----------------------------------------------------------:|
|    `layers.bloom`     |         太阳子树打到此层 → 被辉光 composer 单独捕获         |
| `layers.outerPlanets` | 3 盏外行星补光的图层(发送端在 sun.js,接收端由 `markOuterPlanetsLayer()` 给外行星子树打标) |

## 4. 关键运行时流程

### 4.1 初始化顺序(`initEngine`)

```
1. container.appendChild(renderer.domElement)
2. await initSceneEnvironment(renderer)         环境贴图(EXR → PMREM)
3. await initSkySphereTexture(); scene.add(...) 天空球
4. await initSun(); scene.add(sunAxis)           太阳 + 4 盏光源
5. await initPlanets(); 逐颗 scene.add(...)     8 颗行星(并行加载)
6. (DEV) axesHelper
7. createOrbitControls(camera, ...)              轨道相机控制器
8. initComposers()                               双 composer 辉光管线
9. markAsBloomObject(sunAxis)                    太阳子树打 BLOOM Layer
10. markOuterPlanetsLayer()                      外行星子树打 OUTER_PLANETS Layer
11. window.addEventListener('resize', ...)
12. startAnimation()
```

返回 `dispose` 函数。

> **失败时由顶层 try/catch 内部回滚**:`dispose()` + `renderer.domElement.remove()` + `scene.clear()` + `throw err`,把已建好的 partial state 清理掉后再让上游感知错误。详见 [引擎初始化错误处理.md](../explain/引擎初始化错误处理.md)。

### 4.2 动画循环顺序(`startAnimation`)

```
每帧:
  1. setSkySphereAutoRotation()    更新天空球
  2. setSunAutoRotation()          更新太阳自转
  3. updatePlanets(true)           更新 8 颗行星(公转 + 自转)
  4. controls.update()             更新控制器
  5. renderBloomFrame()            渲染(双 composer 辉光)
```

**严格规则:所有 state 更新必须在渲染之前**,否则会出现「N 帧渲染的是 N-1 帧的状态」的视觉延迟。

### 4.3 销毁顺序(`dispose`)

```
1. removeEventListener('resize')
2. cancelAnimationFrame(rafId)     停止动画
3. controls.dispose()              释放控制器
4. disposeBloom()                  释放双 composer + darkMaterial
5. renderer.dispose()              最后释放 renderer
```

`controls`、`rafId` 都做了 null guard,**部分初始化状态下调用 dispose 是安全的**。
